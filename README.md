# QuickPick 🎬

QuickPick is an iOS movie discovery app built with SwiftUI that helps users spend less time browsing and more time watching.

Unlike traditional movie recommendation tools, QuickPick lets users **discover films based on how much time they have available**. Whether you have 60 minutes or an entire evening, QuickPick helps narrow down your options to movies that fit your schedule.

### Features
- **Time-Based Discovery:** Filter movies by your available viewing time.
- **Personalized Filters:** Browse by genre, streaming provider, and region.
- **Shake to QuickPick:** Shake your device to randomly select a movie.
- **Not Interested List:** Exclude movies you don't want recommended again.
- **Movie Discovery:** Explore movie posters, ratings, and details using the TMDb API.
- **Saved Preferences:** Persist selected user preferences locally.

### Built With
SwiftUI · Swift · TMDb API · Firebase · UserDefaults

### Motivation
QuickPick was created to address decision fatigue in movie discovery. The goal was to build a simple, intuitive experience that helps users find something to watch without spending their limited free time searching.
